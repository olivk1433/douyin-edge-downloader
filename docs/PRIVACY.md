# 隐私说明

本扩展不含遥测、统计 SDK、第三方视频解析服务或项目方服务器。

## 本地处理

- 识别当前播放器、作品 ID、公开标题、作者昵称及可用媒体信息。
- 在页面内观察网站正常 Fetch / XHR 的作品响应，仅保留必要媒体字段，最多 64 条作品。
- 下载任务的作品信息、媒体地址和状态暂存在 `chrome.storage.session`，不写入同步存储。
- 视频逐块写入网站来源的 OPFS 子目录，再交给 Edge 下载。

完整的临时媒体地址可能含有网站生成的签名。它们只用于该页面的下载任务，不会作为分析数据上传。不要把会话存储、原始接口响应或媒体地址直接贴到公开 Issue。

## 网络与凭据

扩展让播放页面依照正常浏览器来源、Referrer、Cookie 和跨域规则请求媒体。不导出 Cookie、不读取密码，也不伪造请求头。媒体请求、公开作品页和辅助播放页仍由网站及其媒体服务处理，适用网站自身的隐私规则。

## 清理

正常保存后释放 Blob 并删除暂存文件；已就绪但未释放的文件会在三十分钟后回收。异常关闭可能留下暂存文件，下次下载时只清理本扩展子目录中超过 24 小时的旧文件。不会删除网站的其他数据。

公开仓库不包含浏览器配置、实际视频、个人路径、真实作品样本链接或本机下载记录；演示图片采用虚构数据，已移除文本和 EXIF 元数据。
