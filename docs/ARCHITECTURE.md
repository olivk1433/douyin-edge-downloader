# 架构

| 文件 | 职责 |
| --- | --- |
| `extension/manifest.json` | Manifest V3 配置及最小网站权限 |
| `media-capture.js` | 在 MAIN world 观察正常作品响应，缓存必要媒体字段 |
| `scanner.js` | 当前作品绑定、播放器可见性判断、真实分辨率分组 |
| `content.js` | 隔离内容脚本和封闭 Shadow DOM 悬浮卡片 |
| `popup.*` | 工具栏弹窗 |
| `background.js` | 校验内部消息、重新识别、任务锁、有限恢复和下载状态 |
| `refresh-media.js` | 读取一次公开作品页，安全解析而不执行返回脚本 |
| `page-fetch.js` | 页面请求、MP4 文件头检查、OPFS 流式写入及清理 |
| `utils.js` | 网站判断、作品校验、文件名与错误处理 |

下载请求只能来自内部扩展界面。后台重新扫描当前页面取得地址，不接受网页传入任意 URL。只有明确匹配当前作品的源会进入下载候选；手选画质只使用同一分辨率组。

页面任务异步运行，后台以短请求读取进度，避免把整个大文件传输绑定在一次长时间脚本调用上。文件写入磁盘后生成该页面拥有的 Blob URL，交给 Edge 下载 API。

正常地址失败后有限刷新。必要时创建同作品辅助页，开始读取前再次核对原页身份。辅助页保存或失败后自动关闭。429 不进入刷新流程。

内部存储标记沿用既有前缀以保持升级兼容；它们不表示外部服务或个人标识。
